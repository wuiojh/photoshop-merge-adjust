# Photoshop 批量合并调色层脚本

> 一个 `.jsx` 小脚本：把最顶部的调色图层，一次性分别合并进下方每一个可见的纯像素图层，同时原样保留图层名和剪贴蒙版结构。

## 一、这个功能解决什么问题

一张 PSD 里往往有几十个图层，有时候美术或者美工分好图层后想在最上面加个图层整体的调整一下颜色或是明度，但是如果下游是动画要做2D的动画效果需要我们PSD图层是干净的，这样就不允许我们有最上面的调色图层，想给它们统一套一层「色相 / 颜色」调色时，手工做法是：复制调色层 → 拖到某个图层上方 → Ctrl+E 向下合并 → 对每个图层重复一遍。

麻烦的是合并经常带来副作用：图层名被改掉、已经建好的剪贴蒙版被释放、智能对象或形状层被意外栅格化，事后还要一个个修回来。

这个脚本把整个过程一次跑完，并专门处理了这几类副作用：

- **图层名不动**：开场按图层 ID 记录所有名字，收尾逐个校验，绝不按位置批量改名
- **剪贴蒙版不丢**：先统一释放（避免插入图层切断剪贴链），合并完成后按 ID 自下而上原样重建
- **该跳过的绝不碰**：智能对象、形状 / 填充层、调整图层、文字层、隐藏层一律跳过，收尾还会复核它们仍在、名字未变、未被栅格化

## 二、功能详解

| 项目 | 行为 |
| --- | --- |
| 合并目标 | 只合并**可见的纯像素图层**（`LayerKind.NORMAL`，并经 Action Manager 复核） |
| 图层名 | 按 ID 快照 + 收尾校验，保持不变 |
| 图层组 | 组结构保留，只钻进组里处理内部的像素层 |
| 剪贴蒙版 | 开场释放 → 合并 → 按 ID 重建，逐个回读校验 |
| 调整图层（色相/饱和度、曲线…） | 完全跳过，合并后重新剪贴回原本的主体层 |
| 普通像素剪贴层 | 释放后与其它图层「分别」各自合并，再挂回原剪贴关系 |
| 智能对象 | 多重识别（kind / AM 描述符 / layerKind），硬性跳过，绝不栅格化 |
| 形状 / 填充 / 文字 / 3D / 视频层 | 一律跳过 |
| 隐藏图层 | 跳过，可见性用快照精确恢复 |
| 顶部调色层 | 处理完成后移除 |

> 为什么只认纯像素层？形状层和智能对象一旦被合并就会被栅格化、失去可编辑性，而且它们常常是剪贴组的基底。宁可跳过，也不要误伤。

## 三、怎么用

### 第 0 步：先做两件保命的事

**合并是不可逆操作**：会栅格化像素内容、会移除顶部调色层、会执行多步操作（一次 Ctrl+Z 撤不回来）。

1. 把 PSD **另存一份副本**，在副本上运行
2. 运行前在「历史记录」面板点 **创建新快照**，结果不对时点这个快照即可一键回退

### 第 1 步：安装（二选一）

**方式 A · 临时运行（推荐，不用装）**
`文件 → 脚本 → 浏览…` → 选中 `merge_adjust.jsx` → 打开

**方式 B · 装进菜单**
把 `merge_adjust.jsx` 复制到 Photoshop 的 `Presets/Scripts/` 目录，重启 Photoshop，之后从 `文件 → 脚本` 菜单运行。

- Windows：`C:\Program Files\Adobe\Adobe Photoshop [版本]\Presets\Scripts\`
  （没有管理员权限时可用 `%APPDATA%\Adobe\Adobe Photoshop [版本]\Presets\Scripts\`）
- macOS：`/Applications/Adobe Photoshop [版本]/Presets/Scripts/`

完整路径、权限说明和 `.jsx.txt` 后缀坑见 [使用说明.txt](使用说明.txt)。

### 第 2 步：选中调色层

在「图层」面板里**用鼠标点选最顶部那个调色图层**，让它高亮成为当前图层。

⚠ 别选背景层、图层组，也别选下面任何一个普通图层。

### 第 3 步：运行

`文件 → 脚本 → 浏览…`（或方式 B 的菜单项），执行脚本。

### 第 4 步：看结果

结束时会弹出结果提示，包含：完成了几个图层、实际合并与跳过的图层名单及类型、剪贴蒙版释放与重建数量、名字校验修正了几处。

重点检查三样：**图层名有没有变、剪贴箭头还在不在、智能对象 / 形状层是不是原样没动**。

### 第 5 步：结果不对就回退

点「历史记录」里运行前建的那个快照；或者不保存直接关掉文件，重新打开副本再试。

## 四、一个具体例子

处理前（图层面板从上到下）：

```
调色层                ← 运行前选中它
色相/饱和度 1          ← 剪贴到「形状 2」
形状 2                ← 形状层
图层 15               ← 普通像素层，剪贴到「图层 9」
图层 9                ← 普通像素层
智能对象 1
```

运行后：

- `图层 15`、`图层 9` 各自与调色层合并，名字仍是「图层 15」「图层 9」
- `图层 15` ↔ `图层 9` 的剪贴蒙版原样恢复
- `色相/饱和度 1` 仍剪贴在「形状 2」上
- `形状 2`、`智能对象 1` 完全没被碰过
- 顶部调色层被移除

## 五、常见问题

| 提示 / 现象 | 原因与处理 |
| --- | --- |
| 「请先打开一个文档」 | 没打开 PSD，先打开文件 |
| 「请先在图层面板选中【最顶部那个调色图层】」 | 当前选中的是背景层 / 图层组 / 没选中图层 |
| 「没有找到可合并的纯像素图层」 | 下面全是智能对象、形状、文字、调整层或隐藏层，按规则都跳过了；需要处理的先「图层 → 栅格化」并设为可见 |
| 形状层 / 智能对象 / 文字层没变化 | 刻意跳过，是保护性设计，不是故障 |
| 颜色不对 / 少合了一层 | 检查调色层的混合模式与不透明度；确认它本身不是剪贴蒙版；确认目标层可见且是纯像素层 |
| 图层名字变了 / 剪贴蒙版没恢复 | 正常不应发生，欢迎提 Issue 并附结果弹窗截图 |

更多排查步骤见 [使用说明.txt](使用说明.txt)。

## 六、兼容性与反馈

Photoshop CS6 及以上，Windows / macOS。基于 ExtendScript 与 Action Manager，不同版本表现可能略有差异，请先在副本上验证。
